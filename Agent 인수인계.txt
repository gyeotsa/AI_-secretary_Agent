## 2026-07-15 후속 수정

- **[Fix] 원형 사운드바 참조 오류 수정**: 원형 사운드바가 `paintEvent`에서 직접 렌더링되는 구조에 맞춰, 제거된 `circular_sound_bar` 위젯 참조를 상태 변수와 렌더링 갱신으로 교체했습니다. 텍스트 입력, 사운드바 API, 창 모드 전환 스모크 테스트를 통과했습니다.
- **[Test] 통합 실행 진단**: RTX 4060에서 Ollama 모델이 100% GPU로 실행되는 것을 확인했습니다. 하지만 모델이 최종 텍스트 대신 `speak_text` 도구를 반복 호출해 최종 응답 콜백에 도달하지 못했습니다. 따라서 UI 답변 및 자동 TTS가 시작되지 않습니다.
- **[Test] TTS/사운드바 진단**: pyttsx3는 WAV 생성에 성공했지만 `AudioProcessor`는 종료 신호(진폭 0)만 내보냈습니다. 빈 주파수 배열을 받은 사운드바는 `ZeroDivisionError`와 `IndexError`를 발생시켰습니다. 실제 재생 분석과 사운드바 동작은 정상으로 확인되지 않았습니다.
- **[Fix] 응답/TTS 파이프라인 복구**: 워커 스레드의 `QTimer.singleShot()`을 GUI 스레드 신호로 교체해 최종 응답 콜백이 실행되게 했습니다. 자동 TTS가 있는 UI에서는 `speak_text`를 Ollama 도구 목록에서 제외하고, 레거시 JSON 도구 응답도 텍스트로 처리합니다.
- **[Fix] 오디오 재생 및 사운드바 안정화**: TTS 출력 스트림이 재생 완료까지 기다리도록 수정하고, 빈 주파수 배열은 사운드바를 리셋하도록 처리했습니다. 재생 검증에서 오디오 분석 신호 60회(발화 59회), 최대 진폭 100, 활성 막대 31개를 확인했습니다.
