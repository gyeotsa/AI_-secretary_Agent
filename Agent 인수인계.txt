## 📊 프로젝트 기획 배경과 설계 의도

### 1. Harness Engineering 이란?

2026년 AI Agent 분야의 핵심 패러다임 전환:
- **기존**: 모델 자체 성능 향상만으로는 안정적인 프로덕션 시스템 구축 불가
- **현재**: **Agent = Model + Harness**
  - Model: CPU (두뇌)
  Harness: OS (운영체제, 제어 시스템)

**참고 연구:
- arXiv:2605.13357 (AI Harness Engineering: A Runtime Substrate for Foundation-Model Software Agents
- 2026.04 AI 심층분석 보고서
- OpenAI Codex 팀 "Harness Engineering: Leveraging Codex in an Agent-First World

**Harness의 핵심 역할**:
- 컨텍스트 관리, 도구 접근, 프로젝트 메모리, 작업 상태, 관측가능성, 실패 attribution, 검증, 권한 관리

## 🏗️ 프로젝트 구조 설계 의도

```
Jarvis/
├── main.py              # 진입점 (단순하고 명확하게 유지
├── config.py            # 설정 중앙 집중 관리 (환경변수 + Harness 설정
├── requirements.txt     # Phase별로 의존성 분리 (점진적 활성화
├── .env.template        # 비밀 정보 분리 (절대 git에 올리지 않음
├── .gitignore           # 보안과 정리를 위한 파일
├── core/                # 핵심 Harness 레이어
│   ├── __init__.py
│   ├── llm.py          # LLM 추상화 (모델 불가지론)
│   ├── memory.py       # 대화 메모리 관리
│   └── harness.py       # 🌟 안전장치 레이어 (Harness Engineering 핵심)
├── data/               # 데이터 저장소 (SQLite DB)
└── plugins/            # 플러그인/MCP Server 디렉토리 (미래 확장)
```

### 설계 원칙

1. **모델 불가지론 (Model Agnosticism)
   - 언제든지 Claude ↔ GPT ↔ Gemini 전환 가능하도록 LLM을 추상화
   - config.py에 모델 설정 집중

2. **Rippable Architecture**
   - 각 컴포넌트를 독립적으로 교체/제거 가능하도록 모듈화
   - 모델이 발전하면 불필요한 Harness 레이어를 점진적으로 제거

3. **Defense-in-Depth** (심층 방어)
   - 5중 안전장치 계획
     1. 프롬프트 가드레일
     2. 스키마 제한
     3. 런타임 승인
     4. 도구 검증
     5. 라이프사이클 훅
   - Phase 1에서 기초 안전장치만 구현, 나중에 확장

4. **점진적 개발 (Incremental Development)
   - Phase 1~4로 나누어 단계별로 기능 추가
   - 각 Phase가 완료된 후에만 다음 Phase로 넘어감

## 📝 Phase 1 구현 내용 상세

### 1. config.py
- 환경변수 로드 (python-dotenv)
- LLM API 키, 모델 설정
- **Harness 설정**:
  - ALLOWED_PATHS: 파일 접근 허용 경로
  - BLOCKED_COMMANDS: 위험 명령어 블록리스트
- 시스템 프롬프트 중앙 관리

### 2. core/llm.py
- LLMClient 클래스로 Anthropic API 래핑
- Singleton 패턴으로 단일 인스턴스 관리
- chat() 메서드로 간단한 인터페이스 제공

### 3. core/memory.py
- ConversationMemory 클래스로 대화 기록 관리
- SQLite 사용으로 영구 저장
- session_id로 각 대화 세션 구분
- list_sessions()로 세션 목록 조회 기능 (나중에 확장용)

### 4. core/harness.py
- SafetyLayer 클래스: 🌟 Harness Engineering 기초
  - validate_path(): 경로 검증
  - validate_command(): 명령어 검증
  - sanitize_input(): 입력 정화
- Phase 2에서 Tool Use와 함께 사용 예정

### 5. main.py
- CLI 메인 루프
- UUID로 session_id 자동 생성
- SafetyLayer로 입력 정화
- LLM 응답 받아 메시지 저장
