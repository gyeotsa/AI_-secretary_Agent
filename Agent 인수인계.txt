## 📝 주요 구현 내용 상세

### 1. core/llm.py Ollama 지원 강화
- `chat_with_tools()` 메서드에서 Ollama tool_calls 처리
- `/api/chat` 엔드포인트 사용, tools 파라미터 전달
- Anthropic/Ollama 모두 지원하도록 분기 처리

### 2. core/tools.py 기능 확장
- `create_directory()`: 폴더 생성
- `delete_directory()`: 폴더 삭제 (내용물도 같이)
- `create_excel_file()`: 엑셀 파일 생성 (데이터 입력 가능)
- `write_excel_cell()`: 특정 셀에 값 쓰기
- get_tools_schema()에 위 툴들 추가
- **TTS 개선**: pyttsx3 engine을 인스턴스 변수로 유지하여 재사용, 안정성 향상

### 3. config.py 리팩토링
- `APIConfig` dataclass로 환경변수 구조화
- `Config.get_system_prompt()` 메서드로 자비스 스타일 프롬프트 관리
- 시스템 프롬프트에 [GAME]/[WORK] 모드 감지 로직 추가

### 4. ui/main_window.py
- FramelessWindowHint + WindowStaysOnTopHint + Tool
- 상단 DragTab: "DEXTER" 로고, pill 핸들, 구분선
- 중앙 AudioVisualizer: 7개 점 애니메이션
- 하단 정보 패널: 상태 라벨, 사용자 발화, 응답, WORK/GAME 버튼
- ESC로 종료, DragTab으로 창 이동
- 텍스트 입력 필드 추가: QLineEdit로 텍스트 입력 가능, 엔터로 제출

### 5. ui/visualizer.py
- 7개 점, BASE_RADIUS=18
- 상태별 색상/동작:
  - IDLE: cyan, 미세 호흡
  - LISTENING: cyan, 큰 바운스
  - PROCESSING: cyan, 순차 반짝임
  - RESPONDING: purple, 바운스
  - ERROR: red
- wave_data로 애니메이션 제어

### 6. core/state_machine.py
- Enum State: IDLE, LISTENING, PROCESSING, EXECUTING, RESPONDING, ERROR
- `state_changed` pyqtSignal
- `can_transition()`으로 유효 전이 검사
- 각 상태별 transition 메서드 (start_listening(), start_processing() 등)

### 7. core/mode_manager.py
- ModeAppConfig dataclass: name, path, delay, patterns
- `activate_work_mode()`, `activate_game_mode()`
- `_get_snapshot()`, `_find_new_window()`, `_arrange_window()`로 창 관리

### 8. main_qt.py
- DexterApp 클래스: 모든 컴포넌트 초기화
- 상태 머신 연결, 창 가시성/헤트비트 타이머
- 콘솔 입력 테스트 지원
- [GAME]/[WORK] 응답시 모드 매니저 호출
- 음성 토글 버튼 연결: 지속적인 음성 감지 시작/중지
- 텍스트 입력 필드 연결: window.text_submitted 시그널을 _on_user_input과 연결
