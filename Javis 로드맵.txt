# Jarvis 개인 AI OS 개발 로드맵

> Jarvis가 내 PC를 이해하고, 내 일을 대신하는 개인 AI OS로 만들기 위한 단계별 로드맵

---

## 최종 아키텍처

```
                    Jarvis

┌─────────────────────────────────┐
│       Conversation Layer        │
└────────────────┬────────────────┘
                 │
          Agent Runtime
                 │
┌────────────────┼────────────────┐
│                │                │
Planner    Context Engine   Observer
│                │                │
Executor   Memory/RAG      Event Bus
│                │                │
└────────────────┼────────────────┘
                 │
         Permission Manager
                 │
          Tool Runtime
                 │
  Windows / Browser / Apps
```

### STEP 2: Permission Manager → ✅ 완료
**목표**: 안전한 권한 관리 시스템을 구축합니다.

**구현 내용**:
- PermissionLevel Enum: SAFE / CONFIRM / SYSTEM / DENIED
- [core/permission.py](file:///c:/Users/ice31/lepo/AI_-secretary_Agent/core/permission.py)
  - PermissionManager: 권한 요청/승인/거절, 상태 저장
  - CapabilityRegistry: 플러그인 Capability 관리
- UI 연동: [ui/main_window.py](file:///c:/Users/ice31/lepo/AI_-secretary_Agent/ui/main_window.py)에 PermissionRequestDialog 추가

**권한 분류**:
- **SAFE**: 읽기, 검색, 계산
- **CONFIRM**: 삭제, 종료, 메일 전송, Git Push, 파일 이동
- **SYSTEM**: Camera, Microphone, Clipboard, Keyboard, Mouse, Browser, Windows API, Power, Registry, Shell
